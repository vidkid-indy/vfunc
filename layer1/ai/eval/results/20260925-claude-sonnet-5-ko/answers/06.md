## 1. 화면 목록과 상태 지도

**화면 목록**

| 라우트 | 페이지 파일 | 목적 | 필요한 데이터 | 동작 |
|---|---|---|---|---|
| `#/` | `pages/home.js` | 소개 화면 | 없음 | 없음 |
| `#/servers` | `pages/servers.js` | 서버 목록(로딩/오류/빈/목록) | `data/servers.json` (api.js) | 서버 상세로 이동 |
| `#/servers/:id` | `pages/server.js` | 서버 상세 | `data/servers.json`에서 id로 조회 | 즐겨찾기 토글 |
| 그 밖 전부 | `pages/not-found.js` | 찾을 수 없음 | 없음 | 없음 |

**상태 지도**

- 공유 상태 (`store.js`, `vf.store`): `favorites: string[]` — `toggleFavorite(id)`로만 바꿈. 비밀값 없음.
- 페이지 로컬 상태 (컴포넌트 `state`): `servers.js`의 `{ status: 'loading'|'error'|'ready', servers }`, `server.js`의 `{ status: 'loading'|'ready'|'missing', server }`.
- 레이아웃(헤더) 로컬 상태: `{ path, favCount, locale }` — `store`와 `vf.i18n` 구독으로 갱신.
- 언어 선택은 `store`가 아니라 `vf.i18n` + `localStorage`로 관리(새로고침 뒤에도 유지되어야 하므로 즐겨찾기와 요구 조건이 다름).

### store.js

```js
import vf from './lib/vfunc.esm.js';

// Shared state for the whole app. Favorites are intentionally kept in
// memory only (not persisted): the task requires favorites to survive
// navigation and locale switches, but NOT a page refresh.
export const store = vf.store({
  favorites: []
});

export function isFavorite(id) {
  return store.get('favorites').indexOf(id) !== -1;
}

export function toggleFavorite(id) {
  const current = store.get('favorites');
  const idx = current.indexOf(id);
  const next = idx === -1
    ? current.concat([id])
    : current.slice(0, idx).concat(current.slice(idx + 1));
  store.set({ favorites: next });
}
```

### api.js

```js
// All server calls live here. The task provides a static local JSON
// file instead of a real backend, so this module only wraps fetch().
const SERVERS_URL = new URL('./data/servers.json', import.meta.url);

export function fetchServers() {
  return fetch(SERVERS_URL).then((res) => {
    if (!res.ok) {
      throw new Error('Failed to load servers: ' + res.status);
    }
    return res.json();
  });
}

export function fetchServer(id) {
  return fetchServers().then((list) => {
    const found = list.filter((server) => server.id === id)[0];
    return found || null;
  });
}
```

```js
export default function serversPage(ctx, router) {
```

### pages/server.js

```js
import vf from '../lib/vfunc.esm.js';
import { fetchServer } from '../api.js';
import { store, isFavorite, toggleFavorite } from '../store.js';

export default function serverPage(ctx) {
  const id = ctx && ctx.params ? ctx.params.id : undefined;
  let unsubLocale = null;
  let unsubStore = null;

  return vf.vfunc({
    tag: 'section',
    state: { status: 'loading', server: null },
    render: (s) => {
      if (s.status === 'missing' || (s.status === 'ready' && !s.server)) {
        return vf.html`<h1>${vf.t('server.missing')}</h1>`;
      }
      if (s.status === 'loading') {
        return vf.html`<h1>${vf.t('servers.loading')}</h1>`;
      }
      const fav = isFavorite(s.server.id);
      return vf.html`
        <h1>${s.server.name}</h1>
        <p class="server-detail__region">${s.server.region}</p>
        <p class="server-detail__status" data-state="${s.server.status}">${s.server.status}</p>
        <p class="server-detail__url"><a href="${s.server.url}">${s.server.url}</a></p>
        <button type="button" data-action="favorite" aria-pressed="${fav}">
          ${fav ? vf.t('server.favorite.remove') : vf.t('server.favorite.add')}
        </button>
      `;
    },
    delegates: [
      {
        selector: '[data-action="favorite"]',
        eventType: 'click',
        onEvent: (e) => {
          if (e.sender.server) {
            toggleFavorite(e.sender.server.id);
          }
        }
      }
    ],
    onMount(inst) {
      unsubLocale = vf.i18n.subscribe(() => inst.scheduleRefresh());
      unsubStore = store.subscribe(() => inst.scheduleRefresh());
      if (!id) {
        inst.setState({ status: 'missing', server: null });
        return;
      }
      fetchServer(id)
        .then((server) => {
          inst.setState({ status: server ? 'ready' : 'missing', server: server });
        })
        .catch(() => {
          inst.setState({ status: 'missing', server: null });
        });
    },
    onDestroy() {
      if (unsubLocale) {
        unsubLocale();
        unsubLocale = null;
      }
      if (unsubStore) {
        unsubStore();
        unsubStore = null;
      }
    }
  });
}
```

### app.js

```js
import vf from './lib/vfunc.esm.js';
import { store } from './store.js';
import { headerOptions } from './components/header.js';
import homePage from './pages/home.js';
import serversPage from './pages/servers.js';
import serverPage from './pages/server.js';
import notFoundPage from './pages/not-found.js';

const LOCALE_KEY = 'statusboard.locale';

function detectLocale() {
  try {
    const saved = window.localStorage.getItem(LOCALE_KEY);
    if (saved === 'en' || saved === 'ko') {
      return saved;
    }
  } catch (err) {
    // storage unavailable (private mode, disabled storage): fall through
  }
  const nav = (navigator.language || 'en').toLowerCase();
  return nav.indexOf('ko') === 0 ? 'ko' : 'en';
}

function persistLocale(locale) {
  try {
    window.localStorage.setItem(LOCALE_KEY, locale);
  } catch (err) {
    // ignore storage errors
  }
}

function loadLocale(locale) {
  return fetch(new URL('./locales/' + locale + '.json', import.meta.url)).then((res) => {
    if (!res.ok) {
      throw new Error('Failed to load locale: ' + locale);
    }
    return res.json();
  });
}

async function main() {
  await vf.i18n.setup({
    locales: ['en', 'ko'],
    fallback: 'en',
    load: loadLocale
  });
  await vf.i18n.set(detectLocale());
  document.documentElement.setAttribute('lang', detectLocale());

  const appEl = document.getElementById('app');
  let currentPage = null;

  function showPage(factory, ctx) {
    if (currentPage) {
      currentPage.destroy();
      currentPage = null;
    }
    currentPage = factory(ctx, router);
    currentPage.mount('#view');
  }

  const router = vf.router({
    mode: 'hash',
    routes: {
      '/': (ctx) => showPage(homePage, ctx),
      '/servers': (ctx) => showPage(serversPage, ctx),
      '/servers/:id': (ctx) => showPage(serverPage, ctx)
    },
    notFound: (ctx) => showPage(notFoundPage, ctx),
    onChange: (ctx) => {
      const path = (ctx && ctx.path) || router.current().path;
      layout.setState({ path: path });
    },
    linkSelector: 'a[data-link]',
    focus: '#view'
  });

  const layout = vf.attach(appEl, headerOptions());

  layout.setState({
    favCount: store.get('favorites').length,
    locale: detectLocale()
  });

  store.subscribe((state) => {
    layout.setState({ favCount: state.favorites.length });
  });

  vf.i18n.subscribe((locale) => {
    persistLocale(locale);
    document.documentElement.setAttribute('lang', locale);
    layout.setState({ locale: locale });
  });

  router.start();
}

main();
```

### REPORT.md

```markdown
# REPORT

## 가정 (킷이 명시하지 않아 직접 판단한 것)

1. **언어 저장은 직접 구현.** `vf.i18n.setup`에 `persist` 옵션이 있지만 저장 형식(키 이름, 우선순위)이 킷 문서에 없어서, `app.js`가 `localStorage`(`statusboard.locale`)와 `navigator.language`로 초기 언어를 직접 계산하고 `vf.i18n.set()`으로 적용한 뒤 `vf.i18n.subscribe`로 이후 변경을 저장합니다. "저장된 선택 > 브라우저 언어(ko가 아니면 en)" 우선순위를 확실히 지키기 위한 선택입니다.
2. **즐겨찾기는 새로고침에 유지하지 않음.** 과제 문구("페이지 이동과 언어 전환 뒤에도 유지됩니다(새로 고침은 아님)")를 그대로 따라 `store.js`는 메모리에만 상태를 둡니다(localStorage 저장 안 함).
3. **`vf.i18n.setup()`/`vf.i18n.set()`을 Promise로 간주하고 `await`.** 킷에 반환값이 명시되어 있지 않아 `load` 콜백이 비동기인 점에 맞춰 가정했습니다.
4. **라우터 `ctx`에 `{ path, params }`가 있다고 가정.** `routes: { '/servers/:id': (ctx) => … }` 예시만 있고 `ctx`의 정확한 필드는 문서화되어 있지 않아, `ctx.params.id`(상세 페이지)와 `ctx.path`/`router.current().path`(현재 경로 하이라이트)로 가정했습니다. → `VERIFY`
5. **디자인 토큰 이름.** 킷에 확정된 토큰은 `--vf-color-primary`, `--vf-color-text-muted`, `--vf-space-3`, `--vf-chart-1..8`뿐이라, 같은 명명 규칙(`--vf-color-*`, `--vf-space-N`)을 따라 `--vf-color-text`, `--vf-color-bg`, `--vf-color-border`, `--vf-space-1`, `--vf-space-2`를 추가로 썼습니다. DESIGN.md가 없어 "중립 토큰 유지" 규칙대로 `lib/vfunc.tokens.css`만 연결하고 별도 `styles/tokens.css`는 만들지 않았습니다. → `VERIFY`: 전체 토큰 목록과 실제 존재 여부.
6. 서버 상세의 지역/상태/URL 표시는 요구사항 표에 메시지 키가 없어 하드코딩한 라벨 문구를 넣지 않고 데이터 값만 그대로 보여 줍니다(하드코딩 텍스트 금지 규칙을 지키기 위함).
```
