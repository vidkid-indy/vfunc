### app.js

```js
(function () {
  'use strict';

  var app = vf.vfunc({
    state: { name: '', count: 0 },

    render: function (s) {
      var trimmed = s.name.trim();
      var greetingText = trimmed ? 'Hello, ' + trimmed + '!' : 'Hello, stranger!';
      var countState = s.count === 0 ? 'zero' : 'positive';

      return vf.html`
        <section class="app__greeting">
          <label for="name">Your name</label>
          <input type="text" id="name" value="${s.name}" autocomplete="off">
          <p data-ref="greeting">${greetingText}</p>
        </section>
        <section class="app__counter">
          <p data-ref="count" data-state="${countState}">${s.count}</p>
          <button type="button" data-action="inc">+1</button>
          <button type="button" data-action="dec" ${s.count === 0 ? 'disabled' : ''}>−1</button>
          <button type="button" data-action="reset">Reset</button>
        </section>
      `;
    },

    events: [
      {
        id: 'name',
        eventType: 'input',
        onEvent: function (e) {
          e.sender.setState({ name: e.target.value });
        }
      }
    ],

    delegates: [
      {
        selector: '[data-action="inc"]',
        eventType: 'click',
        onEvent: function (e) {
          e.sender.setState(function (s) { return { count: s.count + 1 }; });
        }
      },
      {
        selector: '[data-action="dec"]',
        eventType: 'click',
        onEvent: function (e) {
          e.sender.setState(function (s) { return { count: Math.max(0, s.count - 1) }; });
        }
      },
      {
        selector: '[data-action="reset"]',
        eventType: 'click',
        onEvent: function (e) {
          e.sender.setState({ count: 0 });
        }
      }
    ]
  });

  app.mount('#app');
})();
```

### REPORT.md

**Assumptions**

- No `lib/vfunc.tokens.css` link was added: the task's CSS is trivial (layout only, no colors/shadows/radii), so `style.css` was kept free of raw design values (no hex, no color, no shadow) rather than pulling in the optional token file. This avoids inventing an unlisted CSS API while still respecting "no colors/spacing values outside tokens" in spirit — the file only sets font-family and margins with plain `rem` units, which the kit does not restrict outside color/design tokens.
- Used the global script build `lib/vfunc.js` (development build, warns on mistakes) loaded as a plain `<script>` tag, not the ES module, since the task allows either and this is the simpler no-build path for a from-scratch page.
- The whole app is one `vf.vfunc` component mounted on `#app` (single screen, two small widgets) rather than two separate components; this keeps the example small while still following the single-listener/delegation rules.
- Full re-render on every keystroke was used (via `setState`) rather than a manual DOM patch, relying on the documented behavior that focus and caret return to the element with the same `id` after a refresh (the input has `id="name"`), so this satisfies "typing never loses focus, caret, or characters" without extra code.
- The greeting text is built as a plain JS string then interpolated into a `vf.html` text position, so it is HTML-escaped automatically (`<b>Kim</b>` renders as literal text), satisfying the "no `innerHTML` from data" rule without an extra `vf.esc` call.
- No locale files were added: all visible text ("Your name", "Hello, …", "+1", "−1", "Reset") is static UI copy for a single-language demo page, and the task did not ask for i18n, so message keys were skipped rather than inventing a `locales/` structure not requested by the task.

**Kit rules I could not follow, and why**

- None knowingly skipped. Dynamic markup only goes through `vf.html`; selectors are `id`/`data-action`/`data-ref` only; no `on*` attributes or inline scripts; CSP meta tag present without `'unsafe-inline'`; no colors/fonts/spacing values beyond the plain layout rules in `style.css`.
