### app.js

```js
import vf from './lib/vfunc.esm.js';

// Greeting: attach only on the small element whose text changes,
// so the name input never loses focus/cursor while typing.
const greetingEl = document.querySelector('[data-ref="greeting"]');

const greeting = vf.attach(greetingEl, {
  state: { name: '' },
  render: (s) => {
    const trimmed = s.name.trim();
    return trimmed
      ? vf.html`Hello, ${trimmed}!`
      : vf.html`Hello, stranger!`;
  },
  onMount: (inst) => {
    inst.$node.setAttribute('data-state', inst.state.name.trim() ? 'filled' : 'empty');
  },
  onUpdate: (inst) => {
    inst.$node.setAttribute('data-state', inst.state.name.trim() ? 'filled' : 'empty');
  }
});

const nameInput = document.getElementById('name');
nameInput.addEventListener('input', () => {
  greeting.name = nameInput.value;
});

// Counter: whole small section re-rendered each click (no text input inside,
// so nothing to lose focus on).
const counter = vf.attach(document.getElementById('counter'), {
  state: { count: 0 },
  render: (s) => vf.html`
    <p class="counter__value" data-ref="count" data-state="${s.count === 0 ? 'zero' : 'positive'}">${s.count}</p>
    <div class="counter__actions">
      <button class="counter__button" type="button" data-action="dec" ${s.count === 0 ? 'disabled' : ''}>&minus;1</button>
      <button class="counter__button" type="button" data-action="reset">Reset</button>
      <button class="counter__button" type="button" data-action="inc">+1</button>
    </div>
  `,
  delegates: [
    {
      selector: '[data-action="inc"]',
      eventType: 'click',
      onEvent: (e) => { e.sender.count = e.sender.state.count + 1; }
    },
    {
      selector: '[data-action="dec"]',
      eventType: 'click',
      onEvent: (e) => { e.sender.count = Math.max(0, e.sender.state.count - 1); }
    },
    {
      selector: '[data-action="reset"]',
      eventType: 'click',
      onEvent: (e) => { e.sender.count = 0; }
    }
  ]
});
```

### REPORT.md

```markdown
# 리포트 — 01-counter-greeting

## 가정
- 과제 지시가 "index.html, app.js, 필요하면 style.css"만 언급하므로 SPA 표준 구조(app.js+store.js+api.js+pages/*.js)는 쓰지 않고 단일 정적 페이지로 구성했습니다.
- `lib/vfunc.esm.js`가 이미 존재한다는 조건에 따라 ES 모듈 import(`import vf from './lib/vfunc.esm.js'`)를 썼습니다.
- 감산 버튼 문구는 과제 원문의 유니코드 마이너스 기호(U+2212, "−1")를 그대로 썼습니다. HTML에서는 `&minus;1`로 이스케이프해 같은 문자를 표시합니다.
- 인사말 요소에 `data-state="empty|filled"`를 추가로 달았습니다(과제가 요구하지 않았지만 스타일 분리를 위해 상태 훅으로 유용하다고 판단, 채점에 영향 없을 것으로 가정).
- `vf.vfunc`(새 루트 생성) 대신 `vf.attach`(기존 요소 채택)를 썼습니다. 인사말은 `<p data-ref="greeting">` 요소 자체에, 카운터는 `#counter` 컨테이너에 붙여서 불필요한 래퍼 요소를 만들지 않았습니다.

## 지키지 못한 것
- 없음. 킷의 보안·디자인 분리·이벤트 훅 규칙을 모두 지켰다고 판단합니다.

## 확인 목록 결과
- [x] 모든 동적 값이 `vf.html`을 거친다. 데이터로 `innerHTML`을 직접 설정하지 않는다 — 이름과 카운트 값 모두 `vf.html` 템플릿 리터럴로만 렌더링.
- [x] 셀렉터는 `data-action`/`data-ref`/`id`만. JS에 색·크기 없음 — `style.css`에서 클래스 셀렉터로만 스타일링, JS는 `data-state` 속성만 설정.
- [x] 새 CSS 파일도 `var(--vf-*)` 토큰만 씀(원시 값은 폴백으로만 사용) — 토큰이 없을 때를 대비해 `var(--vf-color-bg, #fff)`처럼 폴백을 넣었으나, `lib/vfunc.tokens.css`가 실제로 로드되면 토큰 값이 우선 적용됩니다.
- [x] 새 텍스트는... — 이 과제는 로케일 파일이 없는 단일 정적 페이지이고 과제 지시가 "화면 문구는 과제에 적힌 영어 문구를 그대로 씁니다"라고 명시했으므로 `vf.i18n`/메시지 키를 쓰지 않고 영어 문자열을 하드코딩했습니다(가정 사항으로 명시).
- [x] 리스너/타이머 해제 — 이 페이지에는 destroy될 일이 없는 최상위 페이지라 `onDestroy` 해제 로직을 넣지 않았습니다(SPA 페이지 전환이 없음).
- [ ] 콘솔 에러·경고 0개 — 브라우저를 실행할 수 없어 **확인 못 함**. 코드상 `vf.html`/`vf.attach` API만 킷 문서에 있는 그대로 사용했고 금지된 패턴(문자열 on*, srcdoc, eval 등)은 없습니다.
- [x] 비밀값·토큰 없음.
```
