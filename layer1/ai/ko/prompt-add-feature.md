# 프롬프트: vfunc.js 앱에 기능 추가하기

**사용법.** 아래 줄 밑의 내용을 기능 요청과 함께 AI에 붙여 넣으세요. AI가 프로젝트의 `AGENTS.md`와 `llms.txt`를 읽을 수 있어야 합니다.

---

당신은 기존 vfunc.js 앱에 기능을 추가합니다. 바꾸는 범위를 최소로 하고 프로젝트의 구조와 규칙(`AGENTS.md`)을 지킵니다.

## 입력
- `REQUEST`: 사용자의 말로 된 기능 요청.
- AI가 읽을 수 있는 프로젝트 파일. 필요한 파일이 보이지 않으면 추측하지 말고 요청합니다.

## 단계
1. **다시 설명**: 기능을 2~4줄로 정리하고 열린 질문을 적습니다. 답에 따라 설계가 달라지면 멈추고 묻습니다.
2. **계획**: 추가·변경할 파일, 새 라우트, store 변경, 새 메시지 키, 새 CSS. 몇 줄 이상 바뀌면 승인을 기다립니다.
3. **구현**: 기존 패턴을 따릅니다. 페이지는 `pages/`, 공용 상태는 `store.js` 함수로, 서버 호출은 `api.js`, 텍스트는 모든 로케일의 메시지 키로, 스타일은 토큰으로.
4. **점검**: 확인 목록으로 점검하고 보고합니다.

## 출력 형식
1. 다시 설명한 기능과 질문(없으면 "없음")
2. 계획
3. 바뀐 파일: 새 파일은 전체, 바뀐 파일은 diff
4. 보고: JS / CSS / HTML / 로케일 / 기타로 나눈 변경 파일과 확인 목록 결과

## 확인 목록
- [ ] 기존 동작이 그대로다(눌러 본 화면을 적기)
- [ ] 새 마크업은 `vf.html`을 거치고 새 이벤트는 `data-action`에 건다
- [ ] 새 텍스트가 모든 로케일 파일에 있고, 날짜·숫자는 `vf.fmt`
- [ ] 새 타이머, 리스너, 구독은 `onDestroy`에서 해제한다
- [ ] JS에 디자인 값이 없고 CSS는 토큰만 쓴다
- [ ] 콘솔 에러·경고가 0개다
