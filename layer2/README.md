# layer2 — class-free components

Stage 2 (in progress, not released yet). `vs*` functions return markup (`SafeHtml`, usable as a string and inside `vf.html`), `vf*` factories return instances. Built only on the public API of layer 1, plus the built-in grid and chart, third-party adapters and the integration kit. Layers 1 and 2 are released together as 1.0.0.

2단계(작업 중, 아직 게시 전). `vs*`는 마크업(`SafeHtml`, 문자열처럼 쓰이고 `vf.html` 안에 넣을 수 있음), `vf*`는 인스턴스를 돌려줍니다. layer1 공개 API만으로 만들고, 기본 그리드·차트, 서드파티 어댑터, 통합 킷을 함께 둡니다. layer1과 layer2는 1.0.0으로 함께 게시합니다.

| Path / 경로 | Contents / 내용 |
|---|---|
| `src/` | `index.js` (every public name), `components/`, `locales/` (en built in, ko as `vfunc-ui.locale.ko.js`), `_internal/` (not public) |
| `css/` | `base.css` + `components/*.css` → `dist/vfunc-ui.css` (`@layer vf.base, vf.components`) and `dist/vfunc-ui.legacy.css` (IE11) |
| `types/vfunc-ui.d.ts` | public API of layer 2 |
| `catalog.json` | component list: tier, category, messages, summary, example |
| `dist/` | generated by `npm run build` — do not edit |
| `test/` | `npm test` |

Load order / 불러오는 순서: `vfunc.tokens.css`, `vfunc-ui.css`, `vfunc.js`, `vfunc-ui.js` (optional `vfunc-ui.locale.ko.js`) — or `vfunc-all.js` for both layers in one file.

See the roadmap on the website (`site/content/en/roadmap.md`).
