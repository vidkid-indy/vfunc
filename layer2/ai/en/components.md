# vfunc-ui components — reference for LLMs

> Generated by build/components.mjs from layer2/catalog.json and layer2/types/*.d.ts. Do not edit.

Layer 2 of vfunc.js: components without classes on top of the engine (`vf.vfunc`). Use them where they save work; plain HTML is still fine.

- **Load:** `vfunc.js` → `vfunc-ui.js` (→ `vfunc-ui-data.js` for the grid and charts) (→ `vfunc-ui.locale.ko.js`), CSS `vfunc.tokens.css` + `vfunc-ui.css`. ES modules: `import 'vfunc/ui'` (and `'vfunc/ui/data'`) add the members to `vf`.
- **`vf.vs*` returns SafeHtml:** put it in `vf.html` templates or `render` as is (not escaped twice). It never holds state.
- **`vf.vf*` returns an instance:** `.mount(el)` or a parent's `childs`. Callbacks get `{ sender, event, data }`: read `e.data`. `getValue()` / `setValue(v)`; `setValue` never calls `onChange`.
- **Hooks:** `id`, `ref` (`data-ref`) and `action` (`data-action`) props; never select by the `vf-*` classes. Every string prop is escaped; pass `vf.html` for markup.
- **Text:** built-in messages are the keys listed per component; override them with props or `vf.i18n.add(locale, { key: text })`.
- Types below are the d.ts declarations without comments. Types used by several components come first.
