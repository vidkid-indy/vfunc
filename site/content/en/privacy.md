# Privacy

- This site uses **no analytics, ads or tracking cookies.**
- Only your theme and language choices are stored in your browser (`localStorage`). They are never sent to a server, and you can clear them in your browser at any time.
- The site is served by GitHub Pages. GitHub may collect server logs under GitHub's privacy statement.
- If comments (giscus) are added, they use GitHub sign-in; this page will say so.
- For questions, use the repository's Issues or the contact in `SECURITY.md`.
